# MULTI-PART VIDEOS

In addition the current Movie Maker implements a multi-part video format. These types of Videos internally carry one of the above types and are generated when a single output file would exceed the fat32 file size limit of 4gbs.

Individually these files are perfectly valid files, Each part may be played in the regular player and individually bookmarked.

The difference is the addition of -PART-xx. In the file name. A group of such files with the same name prefix and named

```
MOVIE-PART-01.SPV
MOVIE-PART-02.SPV
...
MOVIE-PART-10.SPV
MOVIE-PART-11.SPV ... etc.
```

The Multi-Part player PLAYPARTS.PRG (called PARTSPLAYER in older notes) will treat these as a group to be played one after the other !

That program has a separate bookmarking scheme than the other players.

If a multi-part Video is generated by the X16 Movie Maker it’s mini-player will be the multi-part enabled player.

Every part carries the same Shint and, for hint “A”, the same aspect float in the header EXTRA bytes (see Addendum \#3), so each part is displayed with the same window. A multi-part video made with “Keep original aspect” plays correctly part to part.
